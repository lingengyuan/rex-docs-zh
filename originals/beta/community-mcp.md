# Community MCP

Rex documentation, the changelog, and current and past discussions from the
Rex Beta Discord are available to agents as an MCP server.

An agent can use it to search documentation and past commentary and issues from the community,
along with the Superlogical team's commentary and feedback. It can also read the release notes
for every Rex version posted in #changelog.

It's useful for learning about Rex, for seeing what's new or coming, and for
finding the thinking behind decisions that is buried in archived threads. It is 
behind Discord OAuth, and you need to be a member of the Rex Beta Discord server.

## Install


**Note:** We recommend naming the server `superlogical` rather than `rex`,
so it doesn't conflict with Rex skills, instructions, and the CLI.
