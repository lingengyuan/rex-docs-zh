# Installation

**At the current stage of beta testing, the macOS application and the Linux,
FreeBSD and Windows server are available to all testers. The iOS and Windows
applications are available to testers who enroll. See Discord for enrollment
instructions.**

We have a Rex client for Linux that isn't part of testing yet. We hope to
expand the scope of public testing quickly.
