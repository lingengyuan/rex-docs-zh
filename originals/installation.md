# Installation

**At the current stage of beta testing, the macOS application and the Linux
and FreeBSD server are available to all testers. The Windows server is
available to testers with the Windows role in Discord.**

We have Rex clients for iOS, Linux, and Windows at varying stages of
readiness. We hope to expand the scope of public testing quickly, but they
aren't part of testing yet.
