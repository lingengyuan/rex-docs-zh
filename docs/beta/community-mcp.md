# 社区 MCP

Rex 文档、更新日志，以及来自 Rex Beta Discord 的当前与历史讨论，均以 MCP 服务端的形式向智能体提供。

智能体可使用它来搜索文档、社区的历史讨论和 Issue，以及 Superlogical 团队的评论与反馈。它还可以阅读在 #changelog 中发布的各版本 Rex 发行说明。

这有助于深入了解 Rex、查看最新动态或规划中的特性，以及从归档的讨论帖中挖掘决策背后的思考脉络。该服务受 Discord OAuth 保护，需要成为 Rex Beta Discord 服务器的成员。

## 安装

**说明：**建议将该服务端命名为 `superlogical` 而非 `rex`，以避免与 Rex skill、指令和 CLI 产生冲突。
