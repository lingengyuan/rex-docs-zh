# Mac 操作

本页列出 Rex for Mac 命令面板中的所有操作。可以使用操作名称来[绑定快捷键](../customize/keyboard-shortcuts.md)或通过 `rex do` 运行。任何标记为 [Bleeding Edge](mac-settings.md#setting-app-version-update-channel) 的内容均处于该更新通道中，尚未进入 Preview。
